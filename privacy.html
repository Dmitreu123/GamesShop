Политика конфиденциальности

Настоящая Политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей сайта Games Shop.

1. Общие положения

Используя Сайт, Пользователь соглашается с условиями обработки его персональных данных. В случае несогласия Пользователь должен прекратить использование Сайта.

2. Какие данные мы собираем

Мы собираем: email, имя пользователя (никнейм), IP-адрес, данные о транзакциях и историю активности на сайте.

3. Цели обработки данных

Данные используются для идентификации пользователя, обеспечения работы escrow-системы, отправки уведомлений и предотвращения мошенничества.

4. Защита данных

Пароли хранятся в зашифрованном виде. Мы используем современные методы защиты для предотвращения несанкционированного доступа к информации.
